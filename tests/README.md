# 수학 랩 자동 테스트

`lab/index.html`의 회귀 테스트(Playwright headless). 코드 수정 후 커밋 전에 반드시 실행한다.

```bash
cd tests
npm install          # 최초 1회
node run-all.js      # 전체 실행 (크로미움 경로가 다르면 PW_CHROMIUM=... 지정)
```
