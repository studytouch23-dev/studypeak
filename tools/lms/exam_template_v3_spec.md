## 1. 상단 (1~3행)
- 1행: `시험 제목 | 과목 | 시험 시간(분)` / 2행: 값 (과목은 `수학`, 시간은 숫자 int) / 3행: 공백

## 2. 그룹 헤더 행 — 9열
```
그룹 순서 | 대분류 | 소분류 | 유형 | 지문 제목 | 지문 작성자 | 지문 태그 | 시작 페이지 | 종료 페이지
```
- 그룹 데이터 행: A=순서(int, 1~N 통산), B/C/D=대표 유형 3단(필수), E=`"N번"`, F=`지영T`,
  G=과목/학년 태그(예: `공통수학1`), H/I는 시험 양식에서 비움(셀 자체를 만들지 않음 — 고스트 셀 금지)

## 3. 문항 헤더 행 — 14열
```
A 문항 번호 | B 대분류 | C 소분류 | D 유형 | E 정답유형 | F 난이도 | G 권장풀이시간(mm:ss) |
H 답안개수 | I 점수 | J 정답선택지 | K 주관식 정답 | L 비교 유형 | M 단위 | N 답안없음
```
| 열 | 값 (템플릿 샘플 기준) |
|---|---|
| A | 문항번호 문자열, `number_format="@"`. 하위 문제 `2-1`, `2-2` |
| E | `단일 선택` / `다중 선택` / `단답형` |
| F | 기본 `일반적인 문제` (샘플에 채워져 있음; 비워도 되는지는 미검증) |
| G | `datetime.time(0,m,s)`, `number_format="mm:ss"` |
| H | 객관식 = 선택지 개수(5지선다 `5`). 단답형: 샘플은 빈칸이나, v2 실전에서 "답변 수가 필요합니다" 오류 사례 있음 → 단답형도 정답 개수(`1`) 채우는 것을 권장 |
| I | 점수 숫자 |
| J | 객관식 정답 번호 |
| K | 단답형 정답 (HTML 래핑 없이 순수 텍스트/숫자) |
| L | 단답형 복수정답일 때 `순서 있음`/`순서 없음`/`유의어 처리`, 아니면 빈칸 |
| M | 단위 (필요 시만, `_Lookup` D열 값) |
| N | `아니오` (샘플 기준) |

- 타입: 템플릿 샘플은 H/J를 문자열(`'4'`, `'1'`)로 담고 있음. 이전 13열 LMS에서는 int가
  검증됐었음 → 첫 업로드 시 **샘플과 동일하게 문자열**로 맞추고, 오류 나면 int로 재시도.
  결과가 확인되면 이 문서와 CLAUDE.md §0에 기록할 것.
- 복합 유형: 같은 문항 번호를 A열에 반복하는 연속 행에 B/C/D만 채움
- 하위 문항(`2-1`…) 행은 B/C/D 빈칸, E~N 채움

## 4. 빌드 파이프라인
1. `templates/exam_template_v3.xlsx` 복사 → openpyxl로 샘플 행(5,7,9,11~13) 삭제 후
   4행부터 블록 반복 기입 (`_Lookup` 유지)
2. 고스트 셀 제거: 저장 전 `ws._cells`에서 value None인 키 `del`
3. `scripts/recalc.py` → 0 errors, 자기닫힘 `<c/>` 0건 확인
4. `scripts/validate_lms_upload.py`로 최종 검증 (ERROR 0건)
5. LMS 업로드 파일명 ASCII, 사용자 전달 파일명은 한글
