# 수학 문제은행 → HWPX 조판 규칙 (Claude Code용 프롬프트)

> 이 문서는 Claude Code가 수학 문항 30개를 **수능 문제지 양식의 HWPX**로 조판할 때 반드시 따르는 규칙이다.
> 모든 수치는 기준 원본(『2026 이로운 모의고사 시즌1』, 『결정 모의고사 확통』 PDF)을 실측해서 얻은 값이다.
> 규칙끼리 충돌하면 **§0 우선순위**를 따르고, 애매하면 임의로 정하지 말고 질문한다.

---

## 0. 최우선 원칙 (순서대로 우선)

1. **한 쪽에 정확히 4문항.** 왼쪽 단 위 → 왼쪽 단 아래 → 오른쪽 단 위 → 오른쪽 단 아래 순서. 30문항이면 8쪽이다(8쪽에는 29·30번만, §3-4 참고).
2. **두 번째 문항의 시작 위치는 모든 쪽에서 같다.** 문항 길이와 상관없이 '슬롯' 좌표에 고정한다(§3). 위 문항이 짧다고 아래 문항을 끌어올리지 않는다. 남는 공간은 학생의 풀이 공간이다.
3. **한 문항은 절대 쪽이나 단을 넘어가지 않는다.** 슬롯을 넘치면 §9의 넘침 처리 순서를 따른다.
4. 글꼴, 크기, 들여쓰기, 간격은 §5~§8의 표 값을 **그대로** 쓴다. "보기 좋게" 임의로 조정하지 않는다.
5. 수식은 이미지가 아니라 **한글 수식 객체(hp:equation)**로 넣는다. 도형과 그래프만 그림(hp:pic)으로 넣는다.

## 1. 단위와 환산 (HWPX 내부값)

| 단위 | 환산 |
|---|---|
| 1 pt | 100 HWPUNIT |
| 1 mm | 283.465 HWPUNIT (= 2.8346 pt) |
| 글자 크기 | `charPr height` = pt × 100 (예: 11.2pt → `1120`) |
| 수식 크기 | `hp:equation baseUnit` = pt × 100 (예: 11pt → `1100`) |

아래 표에서는 pt를 기준값으로 쓰고, mm와 HWPUNIT(HU)을 같이 적는다. 좌표의 원점은 **용지 왼쪽 위**다.

## 3. 4문항 슬롯 규칙 (위치 고정의 핵심)

### 3-1. 슬롯 좌표 (모든 쪽 공통 기준)

| 슬롯 | 위치 | 시작 y | 끝 y | 높이 |
|---|---|---|---|---|
| A (위) — 2~8쪽 | 각 단의 위쪽 | 150pt (52.9mm) | 620pt (218.7mm) | **470pt / 165.8mm / 47000HU** |
| A (위) — 1쪽 | 제목 블록 아래 | 220pt (77.6mm) | 620pt | **400pt / 141.1mm / 40000HU** |
| B (아래) — 모든 쪽 | 각 단의 아래쪽 | 620pt (218.7mm) | 1067pt (376.4mm) | **447pt / 157.7mm / 44700HU** |

- 원본에서도 두 번째 문항(2·4·9번 등)의 번호 윗선은 **1쪽이든 3쪽이든 같은 높이(≈620pt)**에 있다. 1쪽은 제목 때문에 슬롯 A만 짧아진다.
- 문항 번호 글자의 윗선은 슬롯 시작보다 약 6~7pt 아래에 온다(2쪽~ 첫 문항의 번호 윗선 = 156.7pt).

### 3-2. 구현 방식 (기본: 고정 높이 표 슬롯)

각 문항을 **테두리 없는 1×1 표** 하나에 넣는다.

- 표: 글자처럼 취급(`treatAsChar="1"`), 너비 = 단 너비 32155HU, 셀 높이 = 슬롯 높이(위 표), 바깥 여백 0, 셀 안 여백 0, 테두리와 배경 없음, 세로 정렬 '위'
- 한 단 = 슬롯 A 표 + 슬롯 B 표. 슬롯 B 다음에는 **단 나누기**(`columnBreak="1"`), 오른쪽 단의 슬롯 B 다음에는 **쪽 나누기**(`pageBreak="1"`)를 넣는다.
- 표 셀 높이는 '최소 높이'로 동작하므로 내용이 넘치면 슬롯이 늘어나 버린다. 그래서 **조판 전에 문항 높이를 추정해서 §9로 처리**해야 한다. 표가 늘어나서 다음 슬롯이 밀리는 일은 금지다.
- (대안) 표를 쓸 수 없는 구조라면 문단 '위 간격'으로 슬롯 B의 시작을 맞춘다. 다만 문항마다 계산이 필요하므로 기본값으로는 쓰지 않는다.

### 3-3. 문항 배치 순서

| 쪽 | 왼쪽 단 A | 왼쪽 단 B | 오른쪽 단 A | 오른쪽 단 B |
|---|---|---|---|---|
| 1 | 1 | 2 | 3 | 4 |
| 2 | 5 | 6 | 7 | 8 |
| … | … | … | … | … |
| 7 | 25 | 26 | 27 | 28 |
| 8 | 29 (단 전체) | — | 30 (단 전체) | — |

### 3-4. 마지막 쪽(29·30번)

- 원본 수능 양식과 같이 29번은 왼쪽 단 전체, 30번은 오른쪽 단 전체를 쓴다(고난도 풀이 공간). 슬롯 높이 = A+B = 917pt(91700HU).
- 사용자가 "8쪽도 4칸 그대로"라고 지시하면 29 → 왼쪽 A, 30 → 오른쪽 A에 두고 B 슬롯은 비운다.

| 인라인 수식 | 한글 수식 기본 글꼴(HYhwpEQ) | **11.0pt** | baseUnit 1100 | §6 |

※ 원본 PDF의 글꼴은 이름 없는 Type3로 묻혀 있어서 글꼴명은 글자 모양을 보고 판정한 값이다. **크기·위치는 실측값**이다. 프로젝트에 지정 글꼴이 있으면 글꼴명만 바꾸고 크기와 간격은 그대로 둔다.

### 5-1. 문단 (들여쓰기 · 줄간격)

| 항목 | 값 |
|---|---|
| 문단 왼쪽 여백 | 11.3pt (4.0mm / 1130HU) |
| 첫 줄 | **내어쓰기 11.3pt** → 번호가 단 왼쪽 끝에 걸리고, 둘째 줄부터는 4mm 안쪽에서 시작 |
| 번호 뒤 본문 시작 | 번호 "23." + 공백 → 첫 줄 본문이 단 시작 + 25.7pt(9.1mm)에 오도록 (번호 뒤 공백 1칸, 필요하면 탭) |
| 줄간격 | 실측 줄 피치 ≈ 19.7pt(6.9mm). 한글 '비율' 기준 **175%**(170~180%)로 맞추고 PDF로 검증 |
| 문단 오른쪽 여백 | 0 (단 오른쪽 끝까지) |
| 정렬 | 양쪽 정렬 |

### 5-2. 문단 간격 (세로 리듬)

| 구간 | 간격 |
|---|---|
| 질문 마지막 줄 → 선택지 줄 | 줄 윗선 기준 31.5pt (= 1줄 + 약 12pt, 문단 아래 간격 12pt/4.2mm) |
| 본문 → 독립(별도 줄) 수식 → 본문 | 위아래 각각 약 12~16pt(4.2~5.6mm) |
| 본문 → 그림 / 그림 → 선택지 | 각각 약 17~18pt(6.0~6.3mm) |
| 본문 → 조건 상자 / 조건 상자 → 선택지 | 각각 약 12~15pt |
| "5지선다형"/"단답형" 라벨 아래 → 문항 번호 | 25.7pt(9.1mm) |

### 5-3. 배점 표기

- 형식: `[2점]`, `[3점]`, `[4점]` — 대괄호와 '점'까지 본문 글꼴 11.2pt
- 질문 끝 문장부호("?", ".") 뒤에 **공백 1칸** 두고 같은 줄에 붙인다.
- 그 줄에 들어가지 않으면 **다음 줄로 넘기고 오른쪽 정렬**한다(배점 혼자 한 줄). 배점 앞에서 강제 줄바꿈을 해서 단어가 쪼개지게 하지 않는다.

### 5-4. 단원 라벨 (5지선다형 / 단답형)

- "5지선다형": 고딕 계열 중간 굵기 14.6pt, 사각 상자 39.9 × 8.3mm(113 × 23.5pt), 테두리 0.12mm, 글자 가운데
- "단답형": 같은 글꼴, 상자 28.9 × 8.3mm(82 × 23.4pt)
- 위치: 해당 슬롯 맨 위, 단 왼쪽 끝 + 1.5mm. 라벨이 있는 슬롯도 **슬롯 높이는 바꾸지 않는다**(라벨 공간은 슬롯 안에서 차지).
- 1번 문항 앞에 "5지선다형", **첫 번째 단답형 문항** 앞에 "단답형"을 둔다(문항 데이터의 `type` 값으로 판단).

## 6. 수식 규칙

- 모든 수식은 한글 수식 스크립트로 입력한다(예: `{f(x)} = x ^{3} +2x ^{2} +3`, `lim _{x -> 1} {f(x)-f(1)} over {x-1}`).
- 크기: baseUnit 1100(11pt). 위첨자와 아래첨자는 수식 편집기 기본 비율(원본 실측 지수 7.4pt)을 그대로 둔다.
- **변수는 이탤릭, 함수명·단위·점 이름은 로만**: `sin`, `log`, `lim`, `P`, `N`, `E`, `V`, `σ`는 로만. 점 A, B, C, 선분 이름 `rm AB`도 로만(수능 관례).
- 수식 앞뒤 한글과는 공백 1칸(조사는 붙임: "$f(x)$의 값은").
- 독립 수식(질문 중간에 한 줄을 통째로 쓰는 식): 별도 문단, **왼쪽 정렬, 본문 들여쓰기에서 10.3mm(29.3pt) 더 들여씀**(단 시작에서 40.8pt). 가운데 정렬이 아니다.
- 여러 식을 한 줄에 나열할 때는 쉼표 + 공백 2칸(원본: `P(A|B)=P(B)=1/2,  P(A∪B)=2/3`).
- 분수가 있는 줄은 줄 높이가 자동으로 늘어나도 된다(고정 줄간격 금지).

## 7. 선택지(①~⑤) 배치

| 경우 | 배치 | 탭 위치 (단 시작 기준) |
|---|---|---|
| 기본: 가장 긴 선택지 ≤ 약 44pt(15.5mm) | **한 줄 5개** | 11.3 / 72.5 / 133.7 / 194.9 / 256.1pt (간격 61.2pt = 21.6mm) |
| 선택지가 길 때 | **3개 + 2개** 두 줄 | 11.3 / 114.8 / 218.3pt (본문 폭 3등분, ④⑤는 위 줄의 ①②와 같은 탭) |
| 더 길 때 | 2 + 2 + 1 세 줄 | 11.3 / 166.6pt |
| 아주 길 때(문장형) | 한 줄에 1개씩 | 11.3pt |

- 원문자와 값 사이의 거리: 16.8pt(약 공백 2칸). 원문자 다음에 공백 1칸 + 수식.
- 분수 선택지는 원문자와 분수의 세로 중심을 맞춘다(수식 기준선 정렬).
- 선택지 줄과 줄 사이는 본문 줄간격 + 4pt.
- 단답형은 선택지가 없다. 질문 끝에 배점만 둔다.

## 8. 그림 · 그래프 · 표 · 상자

### 8-1. 도형/그래프 그림 (hp:pic)

| 항목 | 규칙 |
|---|---|
| 배치 | 글자처럼 취급, **단독 문단, 가운데 정렬**. 기준 영역은 '본문 들여쓰기(단 시작 + 11.3pt) ~ 단 끝' — 원본 그림 중심이 이 영역의 중심과 0.3pt 이내로 일치 |
| 위치 | 그림을 가리키는 문장("그림과 같이…")이 끝난 문단 바로 아래, 선택지 위 |
| 기본 너비 | 단 너비의 약 40%(원본 43.8mm × 38.7mm). 허용 범위 35~55%(40~62mm) |
| 최대 높이 | 60mm. 넘으면 비율을 유지해서 줄인다 |
| 위아래 간격 | 각각 약 6mm(17~18pt) |
| 선 굵기 | 0.12~0.2mm(그래프 축 0.12mm, 곡선과 도형 변 0.2mm) |
| 그림 속 글자 | 점 이름은 로만체(A, B, P), 변수와 좌표는 이탤릭(x, y, O), 크기 10~11pt — 본문 수식과 같게 보이도록 |
| 해상도 | 벡터(SVG→EMF/WMF) 우선. 비트맵이면 600dpi 이상의 흑백 PNG |
| 색 | 흑백만. 회색 음영은 15~25% |

### 8-2. 그림 옆 배치(어울림) — 표나 작은 그림이 본문과 나란히 있을 때

- 원본 27번의 표준정규분포표: **어울림, 단 오른쪽 끝에 붙임**(단 끝에서 4.2pt 안쪽), 너비 122pt(43.1mm)
- 본문 질문은 표 왼쪽으로 흐르게 하고, 선택지 줄은 표 아래에서 시작한다(표와 선택지가 겹치면 안 됨).

### 8-3. 표 (hp:tbl)

| 항목 | 값 |
|---|---|
| 선 | 모든 선 0.12mm 실선(바깥 포함) |
| 행 높이 | 18.2pt(6.4mm) |
| 글자 | 표 안 숫자는 수식 11pt, 가운데 정렬 |
| 확률분포표(가로형) | 너비 = 본문 들여쓰기 ~ 단 끝, 첫 열은 `X`, `P(X=x)` |

### 8-4. 조건 상자 (가)(나) / <보기>

| 항목 | 값 |
|---|---|
| 테두리 | 0.12mm 실선 사각형(둥근 모서리 아님) |
| 가로 범위 | 본문 들여쓰기 위치(단 시작 + 10.5pt) ~ 단 끝 − 6.3pt(2.2mm) |
| 안 여백 | 좌우 약 4mm, 위아래 약 3mm |
| 항목 서식 | `(가)`, `(나)` 다음 공백 1칸. 둘째 줄은 `(가) ` 너비만큼 내어쓰기해서 본문 첫 글자에 맞춤 |
| 항목 간격 | 본문 줄간격 + 약 4pt |
| <보기> | 같은 상자, 위 테두리 가운데에 "<보 기>"(본문 글꼴, 띄어쓰기 포함)를 얹고 ㄱ. ㄴ. ㄷ. 항목은 (가)(나)와 같은 규칙 *(원본에 없는 형식이라 조건 상자 규격을 따름)* |

## 9. 넘침 처리 (슬롯을 넘을 때, 이 순서대로)

1. 그림을 최소 너비(단 너비 35%)까지 줄인다.
2. 선택지 배치를 한 단계 압축한다(예: 3+2 → 한 줄 5개가 가능한지 다시 확인).
3. 독립 수식을 인라인 수식으로 바꿀 수 있는지 확인한다(의미가 바뀌면 안 함).
4. 그래도 넘치면 **자동으로 글자 크기나 줄간격을 줄이지 말고** 해당 문항 번호와 초과량(pt)을 보고한 뒤 사용자 결정을 기다린다(선택지: 그 문항을 단 전체 슬롯으로 변경 / 문항 순서 교체 / 그림 축소 허용).

※ 문항 높이 추정식(조판 전 계산): `번호줄 + (본문 줄 수 × 19.7pt) + 독립수식 수 × (수식 높이 + 28pt) + 그림 높이 + 35pt + 상자 높이 + 27pt + 선택지 줄 수 × 24pt + 31.5pt`. 결과가 슬롯 높이의 **60%를 넘으면 경고**한다(풀이 공간이 부족함).

## 10. HWPX 구현 지침

1. **템플릿 방식 우선**: 한글에서 위 규격으로 `템플릿.hwpx`를 한 번 손으로 만들고(글자 모양·문단 모양 스타일, 머리말/꼬리말, 구역 2개, 슬롯 표 1개 포함), Claude Code는 압축을 풀어 `Contents/section*.xml`의 문항 내용만 채운 뒤 다시 압축한다. `header.xml`의 스타일 ID를 직접 만들기보다 템플릿의 ID를 재사용한다.
2. 스타일 이름을 고정해서 쓴다: `문항번호`, `문항본문`, `독립수식`, `선택지`, `배점`, `조건상자`, `라벨`, `그림문단`.
3. 압축 규칙: `mimetype` 파일은 **맨 앞, 무압축(STORED)**. 나머지는 DEFLATE. `META-INF/manifest.xml`과 `Contents/content.hpf`에 새 그림(BinData) 항목을 반드시 등록한다.
4. 다단: `hp:colPr type="NEWSPAPER" layout="LEFT" colCount="2" sameSz="1" sameGap="2260"` + 구분선 `hp:colLine type="SOLID" width="0.3 mm" color="#000000"`.
5. 단/쪽 나누기: 문단 속성 `columnBreak="1"` / `pageBreak="1"`. 빈 줄을 여러 개 넣어 위치를 맞추는 방식은 금지.
6. 수식: `<hp:equation baseUnit="1100" font="HYhwpEQ" ...><hp:script>…</hp:script></hp:equation>`, 글자처럼 취급.
7. 그림: `<hp:pic>` + `hp:pos treatAsChar="1"`(어울림일 때만 treatAsChar="0" + textWrap="SQUARE"), 크기는 HU로 지정.
8. 문항 데이터 입력 형식(권장): `{번호, type: 5지선다|단답, 배점, 본문(수식 토큰 포함), 독립수식[], 조건[], 그림{파일, 너비mm}, 표, 선택지[5]}` — 조판 코드는 이 구조만 읽는다.
