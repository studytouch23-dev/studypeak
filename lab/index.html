③ 문제 구성

아직 담긴 문제가 없습니다. 문제 검색·작업에서 문제를 담아 오세요.

HTML 학습지/교재는 파일 하나에 그림·수식·해설이 모두 들어 있어, 아무 프로그램 없이 더블클릭으로 열어 보고(해설은 버튼으로 열고 닫기) 그대로 인쇄/PDF 저장이 됩니다. 교재(책)는 표지·목차·단원별 구성에 해설이 책 뒤에 모여 있는 형태입니다.
HWPX는 한글(한컴오피스)에서 바로 열어 이어서 편집할 수 있습니다. $...$ 수식은 한글 수식 개체로 변환되어 더블클릭하면 수식 편집기로 열립니다. 변환하지 못한 수식 명령이 있으면 다운로드 시 알려드립니다.
모의고사 양식은 수능 문제지 조판 규칙(A3 2단, 쪽당 4문항 고정 슬롯, 번호 13.2pt·본문 11.2pt·수식 11pt)으로 출력합니다. 부제목 칸에 선택과목명(예: 확률과 통계)을 쓰면 "수학 영역" 옆에 붙습니다. 문항이 슬롯 높이를 넘치면 자동으로 줄이지 않고 먼저 알려드립니다.

☁️ 구글 드라이브 백업·동기화

구글 계정으로 로그인하면 문제 DB를 내 구글 드라이브의 앱 전용 공간에 백업하고, 다른 컴퓨터에서 같은 계정으로 로그인해 그대로 복원할 수 있습니다(기기 간 동기화). 데이터는 선생님 드라이브에만 저장되며, 별도 아이디·비밀번호가 필요 없습니다.

클라이언트 ID 만드는 방법 (최초 1회, 무료, 약 15분)
  1. console.cloud.google.com 접속 → 구글 계정 로그인 → 상단 [프로젝트 선택] → [새 프로젝트] → 이름 예: studypeak-lab → 만들기
  2. 왼쪽 메뉴 [API 및 서비스] → [라이브러리] → "Google Drive API" 검색 → [사용] 클릭
  3. [API 및 서비스] → [OAuth 동의 화면] → User Type 외부 선택 → 앱 이름·본인 이메일 입력 → 저장. [테스트 사용자]에 본인 Gmail 추가
  4. [API 및 서비스] → [사용자 인증 정보] → [+ 사용자 인증 정보 만들기] → [OAuth 클라이언트 ID] → 유형 웹 애플리케이션 → "승인된 자바스크립트 원본"에 https://www.studypeak.co.kr 추가 → 만들기
  5. 생성된 클라이언트 ID(…apps.googleusercontent.com)를 복사해 위 칸에 붙여넣고 [저장] → [① 구글 로그인]
