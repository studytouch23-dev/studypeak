# 스터디피크 수학 랩 (StudyPeak Math Lab)

마이일타 랩(my1ta.com/lab)의 워크플로를 벤치마킹한 **개인 수학 문제 DB + 학습지 제작기**.
GitHub Pages에서 동작하는 100% 클라이언트 사이드 단일 파일 앱(`lab/index.html`)이며,
모든 데이터는 사용자의 브라우저(IndexedDB/localStorage)에만 저장된다.

접속: https://www.studypeak.co.kr/lab/

## 워크플로

1. **문제 올리기** — HWPX·PDF·TXT 업로드(드래그앤드롭) 또는 붙여넣기 → 번호 기준 자동 분할.
   해설 파일을 따로 올리면 같은 번호끼리 자동 매칭.
2. **DB 보강** — 과목/대단원/중단원(편집 가능한 교육과정 프리셋), 학년, 난이도, 출처, 나만의 태그,
   키워드 규칙 기반 자동 단원태그 추천. AI 분할분은 **미검수** 상태로 들어와 교사가 승인.
3. **검색** — 키워드 + 태그/학년/난이도/출처/검수 필터 + bigram 코사인 유사(의미) 검색 + 중복 검사.
4. **학습지 출력** — 바구니(빠른 담기/순서/배점/자동 구성) → 인쇄/PDF, **네이티브 HWPX(한글 파일) 생성**.
   출력 종류: 학생용 / 강사용 / 정답표 / 해설지.

## 설계 스펙(Math Manual Bank 프롬프트) 대비 구현 현황

| 스펙 항목 | 상태 | 비고 |
|---|---|---|
| HWPX/PDF/TXT 업로드, 드래그앤드롭 | ✅ | 브라우저 내 JSZip·pdf.js 파싱 |
| DOCX 업로드 / HWP 바이너리 파싱 | ❌ | HWP는 .hwpx 재저장 안내. 서버 필요 |
| 이미지형 PDF 문항 분리 | ✅ | 본문이 이미지인 PDF를 자동 감지, 번호 앵커(01~20) 좌표 기준으로 문항별 이미지 크롭 등록. 빠른정답·해설 페이지 자동 건너뜀 |
| HWPX 이미지 임베드 | ✅ | 문항 이미지를 BinData로 실제 포함해 출력 |
| 스캔 PDF OCR (이미지→텍스트) | ❌ | OCR API(서버) 필요 — 이미지 문항은 텍스트 없이 이미지로 보존됨 |
| 문항 경계 인식 (1. / 1) / 01. / [1] / 문제 1 / 1번) | ✅ | 공통 지문 그룹·시각적 분리 인식은 미지원 |
| 문제·해설 번호 매칭 (별도 파일 포함) | ✅ | 의미 기반 후보 추천은 미지원 |
| 편집 가능한 교육과정 taxonomy | ✅ | 단원태그 관리 화면 (과목·대단원·중단원 CRUD) |
| 학년·난이도·출처·유형(나만의 태그) | ✅ | |
| AI 자동 분류 + confidence | 🔶 | 키워드 규칙 기반 추천 (confidence 없음). LLM 분류는 서버/API 키 필요 |
| AI 추천과 교사 확정 분리 | 🔶 | 검수(reviewed) 플래그로 구분. 추천 이력 별도 저장은 안 함 |
| 검수 워크스페이스 | 🔶 | 분할 미리보기 + 상세 수정 + 검수 승인/해제 + 미검수 필터. 원본 좌우 대조는 미지원 |
| 키워드/태그/자연어 유사 검색 | ✅ | 유사 검색은 문자 bigram 코사인 (임베딩 아님) |
| 검색 작업 공간 (태그 트리+카드 그리드) | ✅ | 좌측 단원/출처/나만의 트리(건수 표시), 카드 그리드, 30개/페이지, #번호 검색, Shift+클릭 범위 선택 |
| 이미지 유사 검색 | ✅ | 8×8 평균 해시(aHash) — 사진·캡처로 비슷한 이미지 문항 검색 |
| 검색 필터 프리셋 저장 | ✅ | |
| 작업 내역 (업로드·변환·등록·출력 이력) | ✅ | 최근 30건, 문제 등록 화면에 표시 |
| 그림 복원기 (AI 화질 복원) | ❌ | 생성형 AI 서버 필요 |
| pgvector 임베딩·수식 구조 검색 | ❌ | 서버 필요 |
| 중복 파일 감지 (SHA256) | ✅ | 재업로드 시 경고 |
| 중복·유사 문항 탐지 | ✅ | 완전 동일(자동 제외 + 검사 도구), 유사 후보 보고. 자동 삭제·병합 없음 |
| 원본 추적 | 🔶 | 출처 파일명 + 원본 문항번호 저장. 원본 파일 자체 보관·페이지 좌표는 미지원 |
| 시험지: 순서/배점/총점/문서 종류(학생·강사·정답표·해설지) | ✅ | |
| 조건 기반 자동 시험지 생성 | ✅ | 난이도별 수량 지정, 부족 수량 정직 표시 (임의 생성 없음) |
| HWPX 출력 (OWPML 직접 생성) | ✅ | mimetype/version/header/section XML 생성, 한컴오피스에서 열어 편집 가능 |
| 네이티브 수식 개체 출력 | ✅ | `$...$` LaTeX → 한글 수식 스크립트(`hp:equation`) 변환. 분수·루트·극한·시그마·적분·cases·집합·그리스 문자 등 지원 |
| 수식 export diagnostics | ✅ | 변환 수식 개수·미지원 명령을 다운로드 시 보고 (허위 성공 표시 없음) |
| 수식 가져오기(HWPX 수식 개체 → LaTeX) | 🔶 | 가져온 수식 스크립트를 LaTeX 근사 변환해 `$...$`로 보존. 복잡한 수식은 원문 스크립트 유지 |
| PDF → HWPX 변환 (한글 타이핑) | ✅ | 추출 텍스트 기준 변환. 스캔본 OCR·지면 레이아웃 재현은 미지원 |
| DOCX/OMML 수식 출력 | ❌ | 서버 또는 별도 변환기 필요 |
| 수정 이력/버전/soft delete | ❌ | JSON 백업으로 대체 |
| 멀티유저/권한/수만 문항 확장 | ❌ | 개인용 브라우저 DB (무료 한도 표기 1,000문항은 UI 표시용) |

✅ 구현됨 🔶 부분 구현 ❌ 미구현(대부분 서버 필요)

## 서버 전환 로드맵 (필요해지면)

현 구조는 "프론트엔드 + 로컬 DB"로, 서버 전환 시 UI는 유지하고 저장소만 교체하면 된다.

1. **1단계 (현재)**: GitHub Pages 정적 앱. 비용 0, 설치 0. 수백~수천 문항 개인 사용에 충분.
2. **2단계**: 경량 백엔드(FastAPI+SQLite 또는 Supabase) — 기기 간 동기화, 원본 파일 보관, HWP→HWPX 변환.
3. **3단계**: Math Manual Bank 풀스택(PostgreSQL+pgvector, Celery, OCR, LLM 태깅, OMML/수식 AST) —
   수만 문항, 조교 협업, 임베딩 검색이 필요할 때.

## 개발 메모

- 테스트: `scratchpad/smoke.js` (Playwright headless) — 업로드→분할→태깅→검색→학습지→HWPX 생성→재업로드 왕복 검증.
- 외부 의존성: KaTeX, JSZip, pdf.js (cdnjs). CDN 미로딩 시에도 핵심 기능(수식 렌더 제외)은 동작.
- 원본 파일은 앱이 수정·삭제하지 않는다(읽기만 함).
